Gurukul School Manager

A free management system for a community school.

← All projects

Built for a temple-run community school in Brampton, Ontario: enrolments, courses, fees, attendance, schedules and parent access — designed to replace paper forms for around a thousand enrolments a year, at zero running cost.

The system was built and deployed, but the school never adopted it, so the project is paused. The code is kept as a finished piece of work.
